# ADR-005: 备份数据与主数据库故障域分离

## Status
已接受（阶段一落地，V13 迁移 + BackupStorage 抽象）

## Context
原 backup_snapshots.data 与业务表同库存储，主库故障则备份同时丢失（G1）。
导入操作"先删光再导入"无事务保护（G10）。

## Decision
1. 快照数据外置对象存储（S3/MinIO，本地磁盘为回退实现），库内仅存元数据；
2. 数据库启用 WAL 归档（PITR，WP-2）；
3. 导入改为事务内执行 + 失败自动回滚 + 导入前自动快照（独立事务保留恢复点）。

## Consequences
- 更容易：恢复能力质变（对象存储快照 + PITR）；导入不再破坏性
- 更难：引入对象存储运维与成本；清理策略需同时删库内记录与存储对象
