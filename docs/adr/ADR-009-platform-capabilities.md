# ADR-009: 阶段三平台化能力（SSO / 开放 API / 内容市场）—— 设计预留

## Status
已接受（设计预留，物理实现视业务验证启动）

## Context
架构演进路线图阶段三（2027 H2+）的按需能力：多产品统一账号、第三方生态、社区共享卡组。
当前不实现（YAGNI），但需要明确的启用条件与预留设计，避免未来重构。

## Decision
1. **统一账号 SSO**：Identity 拆分后升级为账号平台。技术路径：现有 JWT（kid 轮换）+ OIDC 授权码流；数据模型不预埋 org_id。
2. **开放 API**：网关层（Caddy）提供配额管理（API Key + 每 Key 速率限制），与现有 RateLimitFilter 分域隔离。
3. **内容市场**：Content 上下文增加 DeckShare/DeckTemplate 实体（发布/订阅模型），需 V17+ 迁移，不在阶段一引入。

## Consequences
- 更容易：能力按需启用，不背早期包袱
- 更难：启用时需新增数据模型与网关配置（已预设计）
- 触发条件：多产品并行 / 第三方集成明确需求 / 社区共享需求验证
