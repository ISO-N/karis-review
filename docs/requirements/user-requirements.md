# 用户需求 — Karis Review 闪卡复习软件

## 1. 产品定位

面向追求简洁体验的个人学习者，提供基于间隔重复原理的闪卡复习工具。核心设计理念是"极简、专注"，避免 Anki 等同类软件的功能臃肿和配置复杂。

## 2. 用户角色

- **注册用户**：通过邮箱注册登录的个人学习者，所有数据与用户账号绑定。

## 3. 功能需求

### 3.1 用户认证

| 编号 | 需求描述 |
|------|---------|
| UR-01 | 用户可以通过邮箱地址注册新账号 |
| UR-02 | 用户可以通过邮箱和密码登录已有账号 |
| UR-03 | 用户可以在登录后访问自己的所有数据 |
| UR-04 | 用户可以在登录后退出当前账号 |

### 3.2 牌组管理

| 编号 | 需求描述 |
|------|---------|
| UR-05 | 用户可以创建新的牌组 |
| UR-06 | 用户可以查看自己所有的牌组列表 |
| UR-07 | 用户可以重命名已有牌组 |
| UR-08 | 用户可以删除已有牌组（含牌组内所有卡片） |

### 3.3 卡片管理

| 编号 | 需求描述 |
|------|---------|
| UR-09 | 用户可以在牌组内创建新卡片，包含正面和反面内容 |
| UR-10 | 卡片正面和反面支持富文本格式（粗体、斜体、列表、标题等） |
| UR-11 | 卡片正面和反面支持 LaTeX 数学公式 |
| UR-12 | 卡片正面和反面支持代码块（语法高亮） |
| UR-13 | 用户可以编辑已有卡片的内容 |
| UR-14 | 用户可以删除已有卡片 |
| UR-15 | 用户可以在牌组内浏览所有卡片列表 |

### 3.4 学习与复习

| 编号 | 需求描述 |
|------|---------|
| UR-16 | 用户可以进入"学习模式"，学习牌组中的新卡片（Stage 0） |
| UR-17 | 用户可以进入"复习模式"，按排期算法复习已学习的卡片 |
| UR-18 | 复习时卡片先显示正面，用户思考后手动翻面查看反面 |
| UR-19 | 翻面后用户对本次回忆结果进行评分，三个选项：忘记、模糊、熟悉 |
| UR-20 | 系统根据用户的评分和排期算法，自动安排卡片的下次复习时间 |
| UR-21 | 用户可以查看今日待复习的卡片数量 |

### 3.5 统计与进度

| 编号 | 需求描述 |
|------|---------|
| UR-22 | 用户可以查看自己的学习统计概览（今日复习数、累计学习数等） |
| UR-23 | 用户可以查看每个牌组的学习进度 |
| UR-24 | 用户可以查看自己的复习趋势（如每日复习量图表） |

### 3.6 数据管理

| 编号 | 需求描述 |
|------|---------|
| UR-25 | 用户可以导出自己的全部数据快照（备份） |
| UR-26 | 用户可以通过导入数据快照恢复数据（覆盖恢复：先删除现有数据，再写入备份数据） |

## 4. 非功能需求

| 编号 | 需求描述 |
|------|---------|
| UQ-01 | 系统界面应保持简洁、清爽，避免不必要的视觉元素和配置项 |
| UQ-02 | 桌面端和移动端体验一致，数据实时同步 |
| UQ-03 | 复习操作流畅，翻页和评分无感知延迟 |
| UQ-04 | 移动端适配单手操作，按钮大小符合触控规范 |
| UQ-05 | 时间精度按自然日计算，不精确到小时 |
| UQ-06 | 用户可自定义每日刷新时间（过了该时间点才算新的一天） |
